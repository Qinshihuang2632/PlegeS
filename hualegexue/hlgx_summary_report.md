### v1.1.1(2026-08-09)

**玩法与系统**
- 难度分级:简单(槽10 + 5层 55块)/ 标准(槽10 + 7层 140块)/ 挑战(槽8 + 8层 204块),开局可选
- 按「类别」消除(所有盐类互相可消),任意物质出现概率近似相等,对局保证可解(各类卡牌数 ≡0/≡2 mod 3)
- 卡牌位置配色(同层相邻不同色);居中正金字塔分层 + 像素遮挡解锁
- 技能卡:撤回 / 移出 / 洗牌 每局各 3 次;AI 模拟含洗牌策略与预判救场

**学习与体验(寓教于乐)**
- 悬停卡牌显示 ≤10 字**物质性质简介**(不显示类别以增加挑战性),全部 197 种物质配齐
- 物质图鉴按 7 大类分组,可对照学习
- 音效系统(Web Audio 合成,零音频文件):点击 / 技能 / 消除 / 通关 / 失败 五种音效,可一键静音

**工程与修复**
- 修复挑战模式上限标记(改为动态显示实际槽位数)
- 目录重组:`game one`(主框架)+ `hualegexue`(小游戏包),蓝图静态路径独立避免冲突
- 自动化自检 17 项全过(三策略模拟通关率 100%)

**报告形式**
- 本文档(.md)作为**版本迭代记录**长期维护,新版本追加在末尾
- Word 版报告 `hlgx_summary_report.docx` 由通用脚本 `make_docx.py` 从本文档生成,内容同步

### v2.0.0(2026-08-09)

**大版本 · 血量 / 昵称 / 计时 / 排行榜**

- **血量机制**:上限 3 点;一次选中 3 张不同类扣 1 血;手牌槽满且无 3 张同类时扣除全部血量并立即失败
- **状态栏**:右上角实时显示 剩余血量 / 剩余卡牌 / 正计时(确认昵称后开始计时)
- **结算窗**:显示剩余卡牌、用时、技能次数、超越玩家数;通关与失败均记录
- **排行榜**:单文件 `rankings.json` 存储;按 血量多 → 用时短 → 技能少 排序,三难度分榜,失败也上榜
- **昵称**:开局前输入昵称(参与排行)或勾选「不参与排行榜」;重名首次提示,二次确认自动加 `*001~*999` 序列号
- **大厅**:新增侧边栏「排名栏」,点开查看三难度榜单,可随时清空;化了个学卡片 + 2 个预留槽位
