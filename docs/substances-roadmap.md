## 二、扩充建议(规划,暂不执行)

### 1. 无机化学补充(优先,高考高频)
| 方向 | 建议物质 | 理由 |
|---|---|---|
| 稀有气体 | He、Ne、Ar、Kr、Xe(非金属单质) | 高考"稀有气体"考点常见,现库缺失 |
| 气体单质补全 | 一氧化氮已有;补 SiH₄?不推荐 | — |
| 铵盐补全 | NH₄Cl 已有;补 (NH₄)₂CO₃、(NH₄)₃PO₄ | 氮肥考点 |
| 硫/氮含氧酸盐 | Na₂S₂O₃(硫代硫酸钠)、NaHSO₃、K₂S₂O₈ | 氧化还原考点 |
| 变价过渡金属盐 | KMnO₄ 已有;补 Na₂CrO₄、Cr₂(SO₄)₃、FeS、Cu₂S | 价态判断高频 |
| 常见沉淀物 | Ag₂CrO₄?不推荐(冷门) | — |

### 5. 扩充时的工程注意(不改代码,仅备忘)
1. **数量平衡**:新增物质要按类别成组添加(建议每组 ≥3 种),否则破坏"每类 ≥3 块"与概率均衡断言
2. **简介约束**:每条 `HLGX_DESC` 去除 `,，·` 后 ≤10 字(有 Vitest 断言),新增物质必须补简介
3. **测试联动**:物质库规模断言是 `>100`,新增不影响;但概率差断言(≤0.25)会随数量变化,扩充后需跑 `npm test` 复核
4. **命名规范**:化学式用 unicode 下标(如 C₆H₆),中文名唯一且与 `HLGX_DESC` 键一一对应
5. **建议新增类别候选**:「混合物/气体」(NH₃、Cl₂ 已有单质类)、「离子」不适合;若加"配位化合物"可并入盐类
6. **优先级建议**:先补稀有气体(He/Ne/Ar)+ NH₃ + 甲酸/草酸/尿素 + 苯胺/硝基苯,共约 10-15 种,各类均衡,一次扩充不改类别结构
