### v1.0.0(2026-08-13)

> 更新贡献人:ps、鼠鼠鼠了

**单词数独上线(首版)**

- **玩法**:N×N 棋盘,每行、每列都要拼成一个完整英文单词(word square,暂不做「宫」);部分格子预填为题面,玩家逐格填字母,填满的非法行自动扣血并标红,全部行列均为合法词 → 通关
- **三难度**(单词长度 / 单词难度 / 单局单词数量):
  - 简单:4×4,基础词,挖空 40%,首行全提示
  - 标准:5×5,进阶词,挖空 55%,首行全提示
  - 困难:5×5,**难词表(低频/抽象 344 词)**,挖空 70%,**无首行提示**
- **词库**:高考大纲 4/5/6 字母常见词(4 字母 453、5 字母 573、6 字母 502,按长度自动归组去重)+ 困难难度专用难词表 344 词
- **生成算法**:word square 回溯生成(行词两两不同、前缀索引剪枝、转置列词校验),实测 4×4/5×5 生成率 100%;6 字母的 6×6 word square 经实测在高考词库下生成率为 0(经典数学约束),故困难难度以词难度+提示收紧体现,不采用 6 字母
- **操作**:桌面物理键盘 + 移动端屏幕字母条(A-Z + 退格)双输入,电脑端/手机端通用
- **排行榜**:独立 API /ws/api/rank(KV 键 ws:easy/normal/hard,与化了个学榜单分离),排序 血量↓→填写数↓→用时↑,防刷规则(60s/IP、昵称清洗、违禁词、用时≥10s)与化了个学一致;昵称复用平台昵称
- **测试**:Vitest 6 项(词库质量/三难度生成率与列词校验/难度参数/挖空与预填/通关流程/扣血与修改)

### v1.4.2(2026-08-14)

> 更新贡献人:ps
>
> ⚠ **本条由被双重转码损坏后逆转码修复得到**(置信度 0.95,与代码交叉验证)

**棋盘统一 + 待填数修正**

- **灰格尺寸统一**:未占用(灰色)格原用固定像素(h-12/w-12、sm:h-14/w-14),而单词格用 `1fr` 列宽 fluid 自适应;当某行 W 较大时列宽被压缩,灰格却保持固定尺寸,导致灰格明显大于单词格、网格错位。已改为与单词格一致的 `aspect-square w-full`,整张网格无论 W 大小都整齐统一
- **待填数修正**:右上角「待填 N」原统计整个 grid 中 null 的个数(灰色格也是 null,被一并计入),导致显示的待填空格数虚高。现只统计占用格(单词成分)中未填的格数,即玩家真正还需补充的字母个数(`totalBlanks` 同步修正)

### v1.4.3(2026-08-15)

> 更新贡献人:ps
>
> ⚠ **本条由被双重转码损坏后逆转码修复得到**(置信度 0.95,与代码交叉验证)

**排行榜「技能」统计修正(剩余次数 → 使用次数)+ 版本显示约定**

- **技能定义修正**:排行榜提交的 `tools` 字段原为两道道具(填空提示 + 含义提示)的**剩余总次数**,与化了个学的技能使用次数定义相反——按剩余次数越少排名越靠前,等于「道具用得越多越靠前」,不合理。现改为提交**使用次数**(已用填空提示 + 已用含义提示之和),排名仍按 `tools` 升序(使用次数越少越靠前),与化了个学排行一致
- **显示文案同步**:排行榜规则说明与成绩卡片文案由「提示余量」统一改为「技能使用次数」
- **版本显示约定**:排行榜「版本」列只显示**小游戏版本**(英了个语 v1.4.x,不再显示平台/其他游戏版本);修正历史遗留——早期(单词数独 v1.0.0 上线时刻)提交时误用了化了个学版本号 v2.3.5,该条记录已修正为 v1.0.0
- **简单难度挖空保证修复**(偶发):原「总空格≥4」保证循环对已挖空格重复计数(判断条件写反),导致 `dug` 虚高提前结束、实际仅挖 3 空格即返回,测试偶发失败。已改为跳过已挖空格,且不满足 easy 保证时重新生成(最多 60 次尝试)
