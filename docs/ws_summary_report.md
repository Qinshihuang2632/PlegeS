## 版本历史(新版本追加在末尾)

### v1.0.0(2026-08-13)

> 更新贡献人:ps

**单词数独上线(首版)**

- **玩法**:N×N 棋盘,每行、每列都要拼成一个完整英文单词(word square,暂不做「宫」);部分格子预填为题面,玩家逐格填字母,填满的非法行自动扣血并标红,全部行列均为合法词 → 通关
- **三难度**(单词长度 / 单词难度 / 单局单词数量):
  - 简单:4×4,基础词,挖空 40%,首行全提示
  - 标准:5×5,进阶词,挖空 55%,首行全提示
  - 困难:5×5,**难词表(低频/抽象 344 词)**,挖空 70%,**无首行提示**
- **词库**:高考大纲 4/5/6 字母常见词(4 字母 453、5 字母 573、6 字母 502,按长度自动归组去重)+ 困难难度专用难词表 344 词
- **生成算法**:word square 回溯生成(行词两两不同、前缀索引剪枝、转置列词校验),实测 4×4/5×5 生成率 100%;6 字母的 6×6 word square 经实测在高考词库下生成率为 0(经典数学约束),故困难难度以词难度+提示收紧体现,不采用 6 字母
- **操作**:桌面物理键盘 + 移动端屏幕字母条(A-Z + 退格)双输入,电脑端/手机端通用
- **排行榜**:独立 API /ws/api/rank(KV 键 ws:easy/normal/hard,与化了个学榜单分离),排序 血量↓→填写数↓→用时↑,防刷规则(60s/IP、昵称清洗、违禁词、用时≥10s)与化了个学一致;昵称复用平台昵称
- **测试**:Vitest 6 项(词库质量/三难度生成率与列词校验/难度参数/挖空与预填/通关流程/扣血与修改)
