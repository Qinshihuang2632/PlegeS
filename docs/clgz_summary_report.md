### v1.0.2(2026-08-19)

> 更新贡献人:ps、在下雨

**判定容差修复(模板对称膨胀)+ 调试快照功能**

- **判定容差修复(关键 bug)**:实测写「焰」cover(墨迹覆盖字形)0.96 却不通过——v1.0.1 只膨胀墨迹(2px),模板是细楷体笔画未膨胀,手写粗笔画(7px)边缘大量落在细模板外导致 stray(墨迹在字形外比例)超标。修复:模板也做形态学膨胀(`TEMPLATE_DILATE_R=3`),与墨迹对称容差——判定退化为纯字形结构比对(仅核对字形,不因笔画粗细/位置误判);新增回归测试「粗笔画正确书写→模板膨胀后通过」锁定
- **调试快照**:浏览器控制台执行 `__clgzSnapshot()` 可查看最近一次判定的——目标字、pass/cover/stray/reason、标准字形与墨迹的归一化位图 ASCII 快照(40 列字符画,直观对照差异),用于调阈值与排障;实现:`setLastDebug/getLastDebug` 存储 + `bitmapToAscii` 渲染
- **测试**:Vitest 11 项(含回归:旧算法不通过/新算法通过),全量 72 项通过

### v1.0.1(2026-08-19)

> 更新贡献人:ps、在下雨

**识别算法重做(手写输入法式)+ 缩写修正(clgx → clgz)**

- **识别算法重做(核心)**:v1.0.0 用「SVG 字形渲染 + 像素重叠」比对,正确书写识别相似度仅 ~0.2(手写笔画粗细/位置与印刷字形差异大);现改为**手写输入法式**算法——
  - **归一化**:取墨迹包围盒,缩放平移填满标准网格(玩家写小/写偏都容忍,与输入法自动缩放一致)
  - **形态学膨胀**:墨迹与标准字形膨胀 r=2 像素,抹平笔画粗细、连笔/断笔差异
  - **仅字形覆盖判定**:墨迹覆盖标准字形比例 cover ≥0.45 且落在字形外比例 stray ≤0.5 判定通过;**不再因 SVG 路径/笔画数判断相似度**——只核对字形结构
- **书写防滚动**:书写开始(pointerdown)锁定页面滚动(html/body overflow hidden),抬起/取消/卸载恢复——手指书写时页面不再位移/抖动
- **缩写修正**:错了个字缩写由错误的「clgx」统一改为拼音缩写「clgz」(cuolegezi)——目录 `src/game3/` 内组件/常量(ClgzPage/ClgzRules/CLGZ_*)、路由 `/clgz`、API `/clgz/api/rank`、KV 键 `clgz:`、`_routes.json` 白名单、文档 `docs/clgz_*.md` 全部同步;英了个语沿用缩写 ylgy 同风格的独立版本体系
- **测试**:Vitest 10 项(归一化位置容忍/写对/写偏/写小/空白/形状不符/乱画/漏笔 + 笔画渲染 2 项),全量 71 项通过

### v1.0.0(2026-08-19)

> 更新贡献人:ps

**错了个字上线(首版 · 手写输入)**

- **玩法**:局内选择考察科目(可单选,也可化学+生物等多选,共 6 科)→ 系统随机抽取所选科目范围内的字 → 玩家在画框内**手写**该字(提示词如「锥形瓶」中的「锥」)→ 字形匹配判定对错 → 每局 8 题,写对 1 字得 1 分
- **手写输入(核心)**:画框为正方形 Canvas,鼠标(端游)/手指或触控笔(手游)直接书写,**不经过键盘**——考察的是真正会写这个字,而非认识拼音;类似「你画我猜」的画框,支持清除重写
- **书写判定(字形匹配)**:玩家墨迹与系统渲染的标准字形做像素重合度比对——`cover`(墨迹覆盖字形比例)≥0.45 且 `stray`(墨迹落在字形外比例)≤0.5 判定通过;写字潦草/写错字/笔画乱飞 → 重合度低 → 不得分,并按原因提示(empty / too_faint / too_messy / wrong_char)
- **考察范围(待审查)**:6 科 165 字——化学 40(锥形瓶/坩埚/羧基/焰色反应)、生物 26(睾丸/吞噬/哺乳/草履虫)、语文 40(羸弱/窠臼/魑魅魍魉/饕餮)、数学 16(菱形/椭圆/幂函数)、物理 18(砝码/衍射/洛伦兹)、史地 25(嬴政/张骞/莫高窟/鄱阳湖);完整清单见 `docs/clgz_characters.md`
- **排行榜**:独立 API `/clgz/api/rank`(KV 键 clgz:all,与化了个学/英了个语榜单分离),排序 **得分↓ → 用时↑**(同分用时短者靠前);防刷规则与化了个学一致(60s/IP、昵称清洗、违禁词、≥10s、同名放开);主排行榜新增「错了个字」tab(综合单档,展示得分/用时/版本),玩法介绍弹窗新增第三子页
- **大厅**:第三张游戏卡「错了个字」上线,原「敬请期待」占位卡移除;主页玩法介绍改三子页切换(化了个学/英了个语/错了个字)
- **测试**:Vitest 7 项(手写判定:写对通过/空白/写错位置/乱画/半写 + 笔画渲染 2 项),全量 68 项通过
