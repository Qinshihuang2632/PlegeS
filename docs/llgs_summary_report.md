### v1.0.0(2026-08-30)

> 更新贡献人:ps、wcx

**历了个史上线(首版 · 时间轴排序)**

- **玩法**:每局 5 张课标历史事件卡,玩家把卡片按时间先后排成一行(最早的放最左);点「提交判定」逐卡比对——归位正确的卡**变绿锁定**,错位卡**标红**可继续调整,全部归位 → 通关
- **无血条(宽容理念)**:不设扣血,多提交几次也能通关;失误 = 提交判定次数
- **提示道具**:每局 2 次,自动把一张错位卡放回正确位置并锁定(计入排名,台词与配了个平提示一致)
- **交互**:点两张卡交换位置(pointer 事件,手机/电脑通用),卡片在判定与拖动间有明确视觉态(绿=锁定/红=错位/主色=拖动中)
- **难度三档**(题库池 + 事件组合):
  - 简单:中国古代史 + 近现代常识,年份跨度大;
  - 标准:+ 近代史与世界史(鸦片战争、两次世界大战等);
  - 困难:全库随机 + 相近年份易混事件(如 1861 年的洋务运动/俄国改革/美国南北战争,同年事件同局不共现保证答案唯一)
- **题库**:60 条课标高频事件(含年份/时代标签/一句话教育简介),年份互异;后续可持续扩充
- **排行榜**:独立 API `/llgs/api/rank`(KV 键 `llgs:easy/normal/hard`),排序 **归位张数↓ → 用时↑ → 提交次数↑ → 提示使用↑**;防刷与各游戏一致(60s/IP、昵称清洗、违禁词、≥10s、单榜 200、v2.8.0 一次性会话令牌)
- **平台接入**:大厅第七张卡(替换「敬请期待」占位,主界面 7 卡:6 可玩 + 错了个字维护中)、玩法介绍第六子页、排行榜第六 tab、后台榜单管理/数据看板同步(game=llgs)、未参与排行游玩上报后台
- **测试**:Vitest 7 项(题库规模与年份唯一 / 抽题年份互异 / 初始乱序 / 判定锁定与通关 / 错位标注 / 提示道具 / 完整一局);全量 127 项通过

### v1.2.0(2026-09-05)

> 更新贡献人:ps

**困难模式同年并列机制 + 题库扩至 217 条**

- **困难模式解除年份去重**:允许同一年的事件同时出现(如 1861 洋务运动/俄国农奴制改革/美国南北战争),抽卡有 75% 概率强制出现一组同年事件(天然 ~2% 太低, 并列辨析成为困难核心难度)
- **并列判定(区段模型)**:每张卡的"正确位置"改为**年份区段**——同年事件共享一个连续区段, 卡位于区段内即归位锁定, **区段内上下顺序不限**; 简单/标准无同年, 区段退化为唯一位置, 行为与旧版完全一致
- **UI 同年上下排列**:困难模式同年卡渲染为同一列(上下堆叠、虚线框标注"并列"), 时间轴标注「同年并列 · 顺序不限」; 提示道具自动把卡插入区段内空位并锁定
- **题库三批扩充 143 → 217 条**:教材课文高频延伸(长平之战/黄巾起义/隋朝建立/兴中会/中共三大/五四宪法/南方谈话与十四大/马拉松战役/光荣革命/美国 1787 年宪法/凡尔赛条约/马歇尔计划/柏林墙/欧盟成立等 30 条); 议题严格符合党史国情与现行大政方针
- **审核增补(用户逐条确认)**:题库 217→**240 条**——名称动词化规范(西周分封→武王伐纣、戚继光抗倭→戚继光抗倭台州大捷、太平天国运动→太平天国运动爆发、洋务运动→洋务运动开始、新文化运动→新文化运动兴起;文艺复兴运动→拜占庭帝国灭亡 1453 锚点修正); 新增唐朝建立(618) 及用户审核确认的 C 字头 13 条(巨鹿之战/玄武门之变/八七会议/古田会议/杂交水稻等)与 W 字头 9 条(汉谟拉比法典/波士顿倾茶/萨拉热窝事件/珍珠港事件等); 同年辨析组扩至 30 组

### v1.3.0(2026-09-18)

> 更新贡献人:ps

**卡牌移动交互重做(点选 + 方位按键)**

- **删除拖拽机制**:手游端长按无法移动卡片、端游并列操作不便 —— 整体重做为「点选 + 方位按键」:
  - 点选一张卡(出现选中框), 排序槽下方出现方位按键组;
  - 左/右:与相邻卡交换位置(简单/标准/困难均有);
  - 左上/左下/右上/右下(仅困难):把选中卡移到相邻列的顶部/底部, 与该列构成上下并列;
  - **选中跟踪**:按键操作对象始终是最初点选的那张卡(移动后跟随), 点按其他卡才切换;
  - 简单/标准难度只显示左/右 2 个按键, 困难显示全部 6 个; 无相邻列时对应按键自动禁用。
- **数据结构重做**:线性槽位 → 列模型(`cols[][]`, 列左→右按时间、列内上→下并列), 判定/提示/锁定全部适配; 已归位卡不可点选、不可被移动
- **测试**:重写 11 项(列开局/点选跟踪/左右交换边界/并列移动穿列/同列顺序无关/提示道具/完整一局); 全量 131 项通过
