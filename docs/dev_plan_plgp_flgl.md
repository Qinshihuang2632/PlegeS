## 一、开发顺序与平台版本计划

- **建议先做「分了个类」**:题库零成本(直接引用 `src/game/substances.ts` 259 种物质与类别),交互简单,可最快走通一遍「新增游戏六步」,平台尽快 +1 款可玩;
- **「配了个平」紧随**:关键路径是题库人工编写(可与分类开发**并行**编题),另需配平判定/校验脚本打磨;
- 若倾向先出「配了个平」也可,两者计划独立,顺序不影响设计;
- 平台版本(参照 v2.4.0/v2.5.0 单游戏上线 +0.1 先例):**分了个类上线 = 平台 v2.6.0;配了个平上线 = 平台 v2.7.0**;两款游戏各自从 **v1.0.0** 起独立版本号。

## 二、「分了个类」(flgl,src/game4/)设计

### 玩法

- **形式**:限时分类流水线——屏幕中央出现物质卡(名称+化学式),下方 8 类按钮(2 行 × 4:金属单质/非金属单质/氧化物/酸/碱/盐/有机物/混合物),点击归类即切下一张;
- **局结构**(与平台血量制一致):每局 **20 张**,归错扣 1 血(hp=3),0 血提前结算;答完 20 张结算;
- **限时压力按难度递增**:简单不限时 / 标准每张 5 秒(超时算错)/ 困难每张 3 秒;
- **双类判定**:5 种有机酸双类均可(见决策表);答错时显示一行依据(如「盐酸 = HCl 水溶液 → 混合物」)作为教育反馈;
- **难度三档**(同现有榜单框架,无缝复用):
  - 简单:高频常见物质,8 类均衡抽样;
  - 标准:加入易错物质(盐酸/氨水/水玻璃/漂白液/18K金/生铁/盐酸 vs 氯化氢等);
  - 困难:全库 259 种随机。

### 数据与题库

- **直接 `import` `src/game/substances.ts`**(只引用不修改):name / 化学式 / categories;
- 出题器:按难度过滤 + 类别均衡 + 同局不重复(纯逻辑进 core.ts,可单测)。

### 排行榜

- KV `flgl:easy / flgl:normal / flgl:hard`;
- 排序:**正确数(score)↓ → 用时↑**(与错了个字同构,ranklib/管理端框架零改动;tools 字段填 0 保持 schema 一致);
- 失败局(0 血)也上榜,防刷规则沿用(60s/IP、昵称清洗、违禁词、≥10s、单榜 200)。

### 文件清单

1. `src/game4/`:core.ts(出题/判定纯逻辑)+ FlglPage.tsx + FlglRules.tsx + version.ts(FLGL_VERSION,起 v1.0.0);
2. `functions/flgl/api/rank.js`(以 clgz 的 rank.js 为模板改键/改排序);
3. `public/_routes.json`:+ `/flgl/api/*`、`/flgl`;
4. 前端接入:RankPage GAMES + 模式表、HubPage 卡片(替换占位槽)+ 玩法介绍子页、App.tsx 路由;
5. 后台接入:`functions/admin/api/rank.js` GAMES、admin RanksPage / DashboardPage;
6. `docs/flgl_summary_report.md`(正序)+ platform_log 追加行(含贡献人列)+ docx;
7. 测试:core.test.ts(判定/双类/难度过滤/同局不重复/类别均衡)。

### 预估

题库零成本;前端交互简单;主要工作量在页面 UI 与接入,整体为两款中较轻的一款。

## 三、「配了个平」(plgp,src/game5/)设计

### 玩法

- **形式(混合式)**:每局 **8 题**(同错了个字节奏)从对应难度题库抽取;
  - 简单:**选择题式**——展示未配平方程式 + 2~3 组候选系数组合,点选正确组;
  - 标准/困难:**数字键盘逐系数填写**——每个物质前有系数空位,端游物理键盘 0-9 + 手游屏幕数字条(复用英了个语字母条交互模式);
- **血量**:hp=3,提交错误扣 1 血并可重填,0 血本局结算;
- **判定关键规则**:
  - 系数必须**全部填写**(含系数 1,训练规范;空位视为未填);
  - **必须是最简整数比**——与标准答案成比例(如 2:1:2 对 4:2:4)判错,提示「需化为最简整数比」;
- **星级(仅结算展示,不进排行)**:3 星 = 零失误、2 星 = 1 次失误、1 星 = 多次失误;
- **提示道具**(每局 2 次,同英了个语):自动填入一个正确系数,使用次数计入 tools。

### 题库(equations.ts,首版 90~120 条)

- 结构:`{ id, difficulty(1|2|3), left: 物质[], right: 物质[], answer: 系数[], condition?: "点燃/Δ/催化剂", note?: 一句话知识点评 }`;
- 分档:
  - 简单(约 30):金属与氧气/酸、水的电解、C/S/Fe 燃烧等基础;
  - 标准(约 40):酸碱盐复分解、金属活动性置换、CO/CO₂/CuO 相关制备、石灰系列;
  - 困难(约 30+):Na₂O₂/H₂O₂/Cl₂ 等氧化还原、氮硫化合物、有机燃烧与取代/加成;
  - 离子方程式、热化学(状态标注)留二期;
- **自动校验脚本** `scripts/check_plgp_bank.mjs`:解析物质式元素计数 → 验证 answer 下质量守恒 + 最简比(gcd=1),接入测试命令,防题库事故;编写题库时逐条过校验。

### 排行榜

- KV `plgp:easy / plgp:normal / plgp:hard`;
- 排序:**答对题数(score)↓ → 用时↑ → 提示使用(tools)↑**;其余防刷/平台分离/管理端规则全沿用。

### 文件清单

1. `src/game5/`:core.ts(判定/最简比/比例解拒绝/星级)+ PlgpPage.tsx + PlgpRules.tsx + equations.ts(题库)+ version.ts(PLGP_VERSION,起 v1.0.0);
2. `functions/plgp/api/rank.js`;
3. `public/_routes.json`:+ `/plgp/api/*`、`/plgp`;
4. 前端接入:RankPage / HubPage 卡片(替换占位槽)/ 玩法介绍子页 / App.tsx 路由;
5. 后台接入:admin 三处(同上);
6. `docs/plgp_summary_report.md` + platform_log 行 + docx;
7. 测试:core.test.ts + 题库校验脚本(质量守恒/最简比/难度分档计数)。

### 风险与对策

| 风险 | 对策 |
|------|------|
| 题库人工编写错误(质量不守恒/非最简) | 校验脚本强制,不过校验不许进库 |
| 比例多解(2:1:2 vs 4:2:4) | 判定要求最简整数比,提示文案引导 |
| 长方程式排版溢出 | 卡片字号自适应(化了个学 v2.2.2 先例);反应条件小字标注在箭头上方 |
| 下标渲染 | 沿用 Unicode 下标方案(物质库同款) |
