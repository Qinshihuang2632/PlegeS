# 历了个史 · 题库审核稿(按时间顺序)

> 用途:逐条审核题库(事件/年份/难度档/简介)。中国史与 世界史 分开, 各自按时间先后排列(公元前在前)。
> 共 **240 条**(中国史 164 / 世界史 76); 同一年的事件相邻排列, 便于核对同年辨析组。
