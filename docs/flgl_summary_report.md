### v1.0.0(2026-08-23)

> 更新贡献人:ps

**分了个类上线(首版 · 传送带拖拽分类)**

- **玩法**:传送带式物质分类(类似植物大战僵尸的传送带关卡)——物质卡从流水线右端按固定间隔出现、向左匀速移动入位;传送带位于屏幕偏上方、**最多容纳 5 张**;玩家**拖动**物质卡,放入屏幕中间的 8 类按钮(金属单质 / 非金属单质 / 氧化物 / 酸 / 碱 / 盐 / 有机物 / 混合物,2 行 × 4)
- **判负规则(用户设计, 重要)**:① 血量归零——归错扣 1 血(共 3 点),归错的卡留在传送带上;② **「新卡该出现的时刻」传送带已满 5 张 → 直接判负**。注意不是满 5 张立刻判负:玩家拥有整个出牌间隔的时间清理空位;20 张全部出完后不再出牌、也不会判负,剩余卡可慢慢分完
- **判胜**:一局 20 张物质全部被正确分类
- **难度三档**(出牌间隔 + 题库策略):
  - 简单:间隔 9s,8 类均衡抽样(前 16 张每类恰 2 张),适合熟悉分类标准;
  - 标准:间隔 7s,均衡抽样 + 每张 30% 概率掺入易错物质(44 种:盐酸/氨水/水玻璃/合金/同素异形体/溶液与纯净物对应……);
  - 困难:间隔 5s,全库 259 种完全随机
- **双类判定**:有机酸 5 种(醋酸/甲酸/草酸/苯甲酸/甘氨酸)按「酸」或「有机物」均算对(与化了个学双身份消除一致);归错时显示该物质正确类别作教育提示(如「盐酸属于 混合物」)
- **题库零成本**:直接 `import` 化了个学的 `substances.ts`(259 种物质 + 类别标注 + 有机酸 multi 字段),未新建题库、未改动化了个学代码
- **交互细节**:
  - 指针拖拽(pointer 事件,手机/电脑通用;卡牌 touch-action:none 防滚动),拖拽中有跟随幽灵卡 + 类别按钮高亮命中;
  - 传送带底纹向左匀速滚动(CSS `flgl-belt` 动画);新卡从右端滑入、前卡移除后左移补位(CSS 过渡);
  - 满载时传送带红框 + 「已满载!下一张出现前必须分类」提示;右上常驻下一张倒计时
- **排行榜**:独立 API `/flgl/api/rank`(KV 键 `flgl:easy/normal/hard`),排序 **正确数↓ → 用时↑**;防刷与各游戏一致(60s/IP、昵称清洗、违禁词、≥10s、score 上限 clamp 20、单榜 200);主排行榜新增「分了个类」tab,后台榜单管理/数据看板同步支持(game=flgl)
- **平台接入**:大厅第四张卡(替换「敬请期待」占位,剩 2 个)、玩法介绍弹窗四子页、`_routes.json` 白名单、局内改名二次确认(共享 NameConfirmDialog)、结算失败可见化 + 重试提交、平台昵称共享
- **测试**:Vitest 13 项(出牌调度 / 满载不即负-到点才判负 / 双类判定 / 牌库不重复与均衡 / 易错池全有效 / 出完不判负 / 整局胜利);selftest 新增 5 项(共 107 项全过);全量 87 项通过
