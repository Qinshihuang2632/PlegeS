### v1.0.0(2026-08-23)

> 更新贡献人:ps

**配了个平上线(首版 · 方程式配平)**

- **玩法**:每局 8 道未配平的化学方程式,把每个物质前的系数补齐。两种作答形态:
  - 简单:**选择题式**——三组候选系数组合点选,其中含 ×2 比例陷阱选项(训练最简比意识);
  - 标准/困难:**数字键盘填写**——点击系数空位选中,物理键盘(0-9/退格/回车提交/左右切换)或屏幕数字条输入;
- **判定规则(核心)**:① 所有系数位填满才能提交(**系数为 1 也必须填**,训练规范书写);② 提交正确得 1 分进入下一题;③ 与答案成比例的同倍解(如 4/2/4 对应 3/2/1)判错并提示「请化为最简整数比」;④ 其它错误扣 1 血(共 3 点)、填写保留可直接修改,血量归零本局结算
- **提示道具**:每局 2 次——自动把一个空位/错位填成正确系数并锁定(🔒 标识);使用次数计入排行榜 tools(用得少靠前)
- **星级展示**(仅结算,不进排行):零失误 ★★★ / 失误一次 ★★ / 其余 ★
- **限量标注**:用量不同产物不同的反应照常收录,物质式后括号标注(如 Fe(足量)、CO₂(不足)),括号不是系数位;成对反应分别收录(CO₂+NaOH、Fe+稀硝酸、AlCl₃+NaOH 各两条)
- **题库与校验(工程亮点)**:`equations.ts` 111 条(简单32/标准43/困难36)与 `docs/plgp_equations.md` v0.2 逐一对应;自研化学式解析器(`parse.ts`,支持括号/方括号嵌套、unicode 下标、有机串式、CH₂=CH₂ 双键写法、中文限量标注剔除);Vitest 全量守恒测试锁定——每条方程左右元素守恒 + gcd 最简比 + 字段长度一致,**改题库必须过测试**
- **排行榜**:独立 API `/plgp/api/rank`(KV 键 `plgp:easy/normal/hard`),排序 **答对数↓ → 用时↑ → 提示使用↑**;score clamp ≤8;防刷与各游戏一致(60s/IP、昵称清洗、违禁词、≥10s、单榜 200);主排行榜新增第五 tab(得分+技能双列)
- **平台接入**:大厅第五张卡(替换占位,剩 1 个)、玩法介绍五子页、`_routes.json` 白名单、路由 /plgp、后台榜单管理与数据看板支持 game=plgp(独立 plgpSort 三维排序)、局内排行参与开关(RankPartToggle)、平台昵称共享
- **测试**:Vitest 13 项(守恒全量/id 唯一/字段长度/gcd/解析抽查/选题不重复/正确提交流程/incomplete 拦截/扣血与 lose/比例解判定/提示锁定与耗尽/MC 选项互异且含唯一正解/tick 计时);selftest 新增 5 项(共 112 项全过);全量 105 项通过
