# 默了个写(mlgx) · 古诗文默写记忆游戏 设计与实施

> 起草日期:2026-10-03
> 背景:用户拍板——高考成语考查在下降,语文槽位不做「成了个语」(成语),改做**古诗文默写记忆**;
> 与错了个字分工:**本游戏考记忆(哪个字/哪一句),错了个字考书写(字的写法)**。
> 硬性约束:**全程无键盘输入**(整句挖空打字会被输入法联想/提示破坏记忆考察,一票否决),所有交互均为点选。
> 素材:`src/game6/`(诗了个句 slgj)为**未上线原型**,其 bank.ts 句对库可直接打底;其「飞花令打字」模式因输入法问题废弃(可改造为点选式)。

---

## 一、定位与差异化

- **考察目标**:课标必背古诗文的 ①句对记忆(上下句) ②逐字精确记忆(易错字辨析) ③篇章连续性(不漏句不串序) ④理解性默写(高考题型:给情境写句子)
- **与诗了个句原型的关系**:简单档「名句双向选择」吸收为本游戏题型之一;飞花令打字废弃(输入法提示),改造为「点选式飞花令」备选题型;题库 162 行打底。
- **与错了个字的联动**:本题库逐句标注易错字 → 汇总为错了个字新科目「古诗文」的字单(先在此记不住/选不对 → 去错了个字练写法),双处同步约定同鸣谢机制。

## 二、玩法:三档难度 × 四种题型(一局 8 题,血量 3,全点选)

| 题型 | 交互 | 考察 | 出现档位 |
|------|------|------|------|
| ①句对匹配 | 给上句(或下句)4 选 1;干扰项=同篇它句/意象相近的他篇名句(如「海上生明月」vs「天涯共此时」) | 句对连续记忆 | 简单(为主)+标准 |
| ②**字池拼句(招牌)** | 给 篇目/作者 + 情境 cue(理解性)或上句,从 8~17 张**字块**里按序点选拼出目标句;池含全部所需字 + 形近/音近干扰字(蜡/腊、沧/苍、长/常、至/致…);拼满判题,错=扣血+展示正解 | 逐字精确记忆 + 易错字辨析,**无输入法可借力** | 简单(短句/干扰少)→标准(理解性cue/干扰4~5)→困难(强干扰6~8/长句/同篇形近) |
| ③篇章复原 | 一段节选 4~6 句乱序,点选卡片按原文顺序排好(复用历了个史点选+方位按键引擎) | 篇章连续性/不漏句 | 标准(少量)+困难 |
| ④点选飞花令(备选/困难穿插) | 给令字 + 9 句候选,**点选所有含令字的句子**(多选,含干扰) | 检索式记忆;保留飞花令趣味、去掉打字 | 困难(可选) |

- 题干 cue 按「理解性默写」命题(如:「《琵琶行》中写琵琶女年老色衰后门庭冷落的句子是?」→ 拼出「门前冷落鞍马稀」),这是高考默写的实际考法。
- 判题节奏参考英了个语/配了个平:拼满即时判定,错=标红展示正解 1.5s 进下一题;对=绿色+正确音。
- 每局 8 题,血量 3(扣完失败可重来),「提示」道具 2 次(显示出处与作者/消除 2 个干扰字块,次数计入 tools——与全平台一致)。

## 三、计分与榜单

- 计分:正确数↓ → 用时↑ → 用具次数↑(全平台统一序);三档难度**独立榜单**(同分了个类/历了个史做法)。
- 防刷:复用开局一次性会话令牌 + 60s/IP 限频 + 昵称清洗/违禁词 + 单榜 200 条。

## 四、题库结构(bank.ts,源头在本游戏)

```ts
interface PoemPiece {          // 篇
  title: string; author: string; dynasty: string;
  genre: "诗" | "词" | "文";
  lines: PoemLine[];           // 按原文顺序(篇章复原用)
}
interface PoemLine {
  text: string;                // 整句(去标点存储, 展示时加标点)
  prev?: number; next?: number;// 句对索引
  cue?: string;                // 理解性默写题干(高频考查句必配)
  traps: { ch: string; confuse: string[] }; // 易错字 → 形近/音近干扰字列表(字池+clgz 字单来源)
}
```

- **规模 v1**:高频篇目 30~40 篇 × 每篇 5~10 高频句 ≈ **300+ 句**;全部 cue/traps 需**用户审定**后上线(同历了个史题库 240 条审定流程)。
- 打底素材:`src/game6/bank.ts` 现成 POEM_COUPLETS(课标名句对)+ 飞花令令字池。
- 生成器:字池干扰字按 traps 自动生成;句对选择干扰项按 同篇/同作者/同主题 自动抽取 + 人工复核防歧义。

## 五、与错了个字联动(v1.3.0 起为自动派生, 替代手动双同步)

1. clgz「语文」科目合并古诗文条目(v1.3.1 起, 用户反馈分类交叉; 原计划为独立「古诗文」科目), **运行时直接从本题库派生**(src/game3/chars.ts 引入 src/game6/bank.ts): 每句易错字 traps.ch 全量收录 + 主旨句关键字(POEM_KEY_EXTRAS 按句人工挑选, 约 90 句), 共 313 条/287 字; 本题库改动即实时同步, 无需手动维护;
2. clgz 新题型「名句挖空手写」: 题面给出处《篇名》与原文(目标字挖空□), 玩家手写缺失的字 → AI 识别判定;
3. 教育闭环成立: 默了个写考记忆(选字/拼句), 错了个字考书写(看原文挖空手写)。
