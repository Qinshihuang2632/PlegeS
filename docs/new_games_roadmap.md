## 二、原畅想逐条整理(落地分析)

### 1. 化学元素连连看 / 配对(成本最低)

- **玩法**:元素符号 ↔ 中文名/原子序数配对消除(翻牌记忆或点选配对两种形态可选)。
- **优势**:题库零成本(118 元素);配对引擎与排行榜无缝复用;高一必修一的元素周期表是刚需考点。
- **排行榜**:正确对数↓ → 用时↑ → 失误↑;或按「连续答对数」设计连击维度。
- **扩展位**:难度按「前 20 元素 → 前 54(主族)→ 全 118」递进;可加「族/周期」提示线索。
- **命名建议**(平台「X了个Y」风格,下同):「认了个素」。

### 2. 化学方程式配平闯关(教育价值最高)

- **玩法**:给出未配平方程式(如 `Fe + O₂ → Fe₃O₄`),玩家在系数位填数;进阶关卡给出反应物,从选项中选产物再配平;按步数/用时给星级(1-3 星)。
- **优势**:与化学高考最强关联(配平是必考技能);延续「化了个学」寓教于乐定位;关卡制适合闯关节奏。
- **成本与风险**:题库需人工编写并校验配平系数(可写脚本验证质量守恒自动校对);输入方式(数字键盘/拖拽)需打磨;判定逻辑比配对复杂。
- **排行榜**:星级总分↓ → 用时↑;或「连续通关关卡数」。
- **命名建议**:「配了个平」。

### 3. 物质分类大作战(玩法新颖)

- **玩法**:物质卡片从流水线依次出现,在时限内把它归入 8 类(金属/非金属单质、氧化物、酸、碱、盐、有机物、混合物)之一;归错扣时间或扣分,速度逐渐加快。
- **优势**:**题库直接复用 `src/game/substances.ts` 的 259 种物质与 8 类标注**,零题库成本;物质分类是「化了个学」玩法介绍的明确考点(7+1 类标准);「反应速度 + 准确率」双维度排行玩法上新颖。
- **注意**:有机酸双类别物质(醋酸/草酸等 5 种)需定规则(按主类判 or 双类均可);易错物质(盐酸=混合物)恰是教育点。
- **排行榜**:准确率↓ → 用时↓(双维);或综合分 = 正确数 − 错误×惩罚。
- **命名建议**:「分了个类」。

### 4. 高考数学·速算大作战(成本最低 · 节奏型)

- **玩法**:心算限时闯关——四则运算 → 分数/指数运算 → 简单因式分解(选系数)→ 数列找规律(选下一项);难度随关卡递增,连击加成。
- **优势**:题目**程序生成,无题库成本**;与「化了个学」的消除节奏互补,碎片时间友好;补齐数学学科空缺。
- **注意**:生成器要保证题目答案唯一、难度可控(数值范围分档);「找规律」题需预置模式库防止多解争议。
- **排行榜**:正确数↓ → 用时↑ → 连击最高↓。
- **命名建议**:「算了个数」。

### 5. 历史/语文·知识连连看(复用消除框架,成本最低)

- **玩法**:用现有三消/配对引擎换题库——历史事件↔年份、成语↔释义、古诗词(上句↔下句 / 诗词↔作者)配对消除。
- **优势**:核心引擎现成,开发最快;题库即内容,可分「历史包 / 成语包 / 诗词包」做成子模式。
- **成本重心**:题库编写量(建议每包先 100~200 对,持续扩充);释义类需防歧义(一义多词的对要剔除)。
- **排行榜**:各子模式独立榜单(同现有难度分档思路)。
- **命名建议**:「连了个连」或按学科分别命名(「史了个话」「诗了个词」)。

## 三、补充新想法(接手模型建议)

### 6. 化学·元素周期表拼图(与 #1 同素材,可做进阶模式)

- 给周期表局部挖空,按「第 X 周期第 Y 族」等线索推断元素填入;比连连看更考验结构记忆。
- 可与「元素连连看」合并为一个游戏的两个模式(配对热身 + 拼图进阶),不额外占槽位。

### 7. 物理·公式连连看(物理学科首作)

- 公式 ↔ 物理量/适用场景配对:`v=v₀+at`↔匀变速直线运动、`F=ma`↔牛顿第二定律……
- 题库:高考物理核心公式 + 适用条件约 100~150 条,人工编写一次长期复用;引擎直接复用 #5。
- 命名建议:「推了个导」/「物了个理」。

### 8. 地理·中国政区连连看(题库极轻)

- 省名 ↔ 省会 ↔ 简称三级配对(34 组现成常识题库);进阶可加「国家↔首都」「地形区↔分界线」。
- 省份轮廓 SVG 辨认成本较高,建议二期再做;纯文字配对一期即可上线。
- 命名建议:「识了个图」/「地了个理」。

### 9. 历史·时间轴排序(玩法差异化)

- 给 4~6 张事件卡,拖拽按时间先后排成一列(如:辛亥革命 → 五四运动 → 中共成立 → 南昌起义);排对全部才算过。
- 与连连看形成玩法差异(排序 vs 配对);题库可直接复用 #5 的「事件-年份」对。
- 命名建议:「排了个序」。

### 10. 语文·飞花令/诗词填句

- 给上句选下句(选择题形式),或「飞花令」模式:限时内轮流输入含指定字的诗句(从课标必背篇目题库中选)。
- 手写输入诗句难度过高,建议纯选择/点选;可复用错了个字的「科目多选」交互。
- 命名建议:「诗了个句」。

### 11. 生物·过程排序(备选)

- 光合作用/呼吸作用步骤排序、细胞分裂时期排序;题库小(高频过程 ~20 套),玩法复用 #9 排序引擎。

### 系统级想法(不占槽位,可附着任意游戏)

- **每日挑战**:全平台同一天同一题(固定种子),按完成用时/得分单独设「日榜」,增强日活与回访;所有游戏共享一个入口。
- **错题回顾**:各游戏记录答错的题(元素/成语/方程式),定期回顾重做;错了个字待定的「错题回顾」可升格为全平台模块。
- **知识点标签统计**:玩家能力画像(按学科/知识点正确率),主界面显示「化学 82% · 历史 64%」式的趣味报告。

## 四、优先级建议(供决策,最终以用户拍板为准)

三个占位槽的推荐组合:

- **组合 A · 快速填充**(成本优先):#1 元素连连看 + #4 速算 + #5 知识连连看 —— 三者均有现成引擎/题库/生成器,可最短时间清空占位。
- **组合 B · 学科铺开**(定位优先,倾向推荐):#4 速算(数学)+ #5 知识连连看(历史/语文)+ #7 物理公式连连看(物理)—— 符合 v2.3.5 确立的「高考知识合集,不限于化学」定位,五大学科各有一作。
- **组合 C · 化学深化**:#1 + #2 + #3 —— 把化学做成平台王牌(元素/配平/分类三层),但学科单一。
- 兼顾节奏的折中:**#1(热身,成本最低)→ #4(数学)→ #5(史语)**,再按反馈决定第二批(#2 配平 / #7 物理)。

确认后第一步:**给每个入选游戏定正式名称与文件缩写**(问用户),再按「新增游戏标准模式」六步实施。
